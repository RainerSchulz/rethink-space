RE-THINK SPACE — Website (Entwurf)
==================================

So einsetzen
------------
1. Den kompletten Inhalt dieses Ordners nach Z:\Projekte\Re-Think kopieren.
   Wichtig: index.html & Co. muessen NEBEN dem vorhandenen Ordner "Bilder" liegen,
   nicht darin. Die Datei Bilder\hero-moon.jpg aus diesem Paket in den vorhandenen
   Bilder-Ordner legen (sie ist neu, ueberschreibt nichts).
2. index.html im Browser oeffnen — fertig. Es wird kein Server benoetigt.

Noch zu erledigen
-----------------
- Portrait als Bilder\Lierfeld.jpg ablegen (Hochformat 3:4). Solange die Datei
  fehlt, zeigt die Autorenseite einen Platzhalter.
- Bildzuordnung pruefen: Die Bilder wurden nach Dateinamen zugeordnet, ohne dass
  ihr Inhalt bekannt war. Aendern laesst sich das in der jeweiligen HTML-Datei
  (Suche nach "Bilder/").
- Texte pruefen: alle Inhalte sind Entwuerfe, zweisprachig hinterlegt als
  <span class="de">...</span><span class="en">...</span>.
- Buchangaben (Verlag, Jahr, ISBN) auf autor.html ergaenzen.
- E-Mail-Adresse kontakt@re-think-space.de durch die echte ersetzen
  (kommt in kontakt.html und im Footer jeder Seite vor).
- Kontaktformular an einen Versanddienst anbinden oder entfernen.
- Social-Links: nur LinkedIn ist gesetzt. X, Instagram und YouTube fehlen,
  weil keine Profil-URLs vorlagen.
